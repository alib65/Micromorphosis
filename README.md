# Micromorphosis
Micromorphosis is a series of compositions exploring solutions for modulating between different microtonal scales, such as 7-, 14-, 15-, and 30-EDO. In this project, Python serves as a bridge connecting the audio generated in SuperCollider with HTML-based visuals. This is an ongoing series, and I plan to add more pieces in the future.
